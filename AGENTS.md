# Инструкция для ИИ-агентов

Проект: распознавание судебных документов о банкротстве и создание карточек
должников в СРО (`sroarbitr.sro-service.ru`).

**Сначала прочитай `memory-bank/00-start-here.md`** — это оглавление банка
памяти. Оттуда открывай только нужный файл, а не весь банк.

Полные правила работы лежат в `.cursor/rules/`. Самое важное из них:

- Владелец проекта ценит экономию токенов. Не читай `out/*.png`,
  `out/form_map.json`, `.venv/`, `samples/*.jpg` — конспекты в банке памяти.
- Элементы формы СРО ищи по идентификаторам из `memory-bank/30-sro-platform.md`,
  а не по подписям: подписи в ASP.NET WebForms неоднозначны.
- Никогда не запускай `run --live` сам — это запись в реальный реестр.
- Документы содержат персональные данные: ничего не отправляй в сторонние
  облачные сервисы, OCR намеренно локальный.
- Крупную механическую работу (новый сценарий по образцу, страницы интерфейса)
  делегируй субагенту на дешёвой модели — см. `.cursor/rules/50-delegation.mdc`.
- Закончив задачу, обнови `memory-bank/50-progress.md`.
