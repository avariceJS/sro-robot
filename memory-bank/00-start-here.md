## Documentation rules

Keep documentation compact, factual and English-only. Distinguish implemented, verified, target and unknown behavior. The owner-requested path is the ordinary-browser KAD helper and local PDF import. The old MKAD/WebDriver adapter is retired. The unused public-source search and the Safari diagnostic have been removed. Historical KAD outbox rows stay withheld and are not dispatched. Update `.now.md` after meaningful changes. Source code and fresh evidence outrank old notes; correct stale claims when found.

Never read `.env`, browser profiles, private local storage or sample documents unless required. Do not expose personal data. Never save or modify a real SROArbitr record.
