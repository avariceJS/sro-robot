# Что за проект

Автоматизация ручной работы в компании, которая занимается делами о банкротстве
(СРО арбитражных управляющих, Ассоциация «НАЦАРБИТР»).

## Ручной процесс, который заменяем

1. Приходит бумажный или электронный документ по делу о банкротстве: чаще всего
   **определение** суда о принятии заявления, реже заявление или решение.
2. Сотрудник вручную ищет дело на `kad.arbitr.ru` по номеру, чтобы получить
   электронную копию и копировать из неё текст.
3. Заходит в `sroarbitr.sro-service.ru`, в реестре физлиц ищет должника по ФИО:
   проверяет, не завёл ли карточку кто-то другой.
4. Если карточки нет — создаёт: ФИО в именительном падеже, ИНН (а при его
   отсутствии — номер дела), номер дела в комментарий, статус «Должник».
5. На вкладке «Контакты» добавляет адрес, выбирая тип: адрес регистрации, если
   так написано в документе, иначе фактический.

Объём: **больше 50 документов в день**.

## Ключевое упрощение

Шаг с `kad.arbitr.ru` из процесса **убран**. Все нужные данные (ФИО, ИНН, СНИЛС,
дата рождения, адрес регистрации) есть в самом документе, а КАД использовался
только как способ получить текст для копирования. Вместо него — OCR.

Это важно ещё и потому, что автоматический сбор в КАД противоречит правилам
сайта и упирается в антибот-защиту. Если данные из КАД однажды понадобятся,
легальные пути: кабинет «Мой арбитр» (компания — участник дел), API Федресурса,
платные агрегаторы (Casebook, Контур.Фокус, Seldon).

## Границы

Поддержаны только должники-физлица. Юрлица живут в другом разделе платформы
(`/register/firm_list.aspx`) и пока не автоматизированы.

Человек из процесса не убирается: оператор сверяет распознанные поля со сканом
перед записью. Цена ошибки в карточке должника выше экономии 20 секунд.
